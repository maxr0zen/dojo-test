# Люма + Додзё Медиа

Общая статическая галерея двух существующих проектов. Node.js нужен для разработки и сборки; опубликованный dist работает на обычном статическом хостинге без Node.js и SPA fallback.
# https://maxr0zen.github.io/dojo-test/

## Визуальные отличия от драфтов Figma

В проекте два разных исходных макета. «Люма» развивалась из драфта блока услуг и записи в полноценную страницу; «Додзё Медиа» сохраняет композицию своего макета значительно ближе. Общая стартовая галерея создана отдельно для объединения сайтов.

Описание ниже составлено по текущим HTML/CSS/React-исходникам и сохранённым локальным отчётам. Новое получение макетов из Figma и попиксельное сравнение в рамках этого обновления README не выполнялись. Исторические отчёты содержат промежуточные варианты: при расхождении приоритет имеет текущая реализация.

### «Люма»: оформление расширено относительно исходного драфта

Основа сравнения — фреймы 5:19110 (1440 × 936) и 5:9483 (390 × 1057), описанные в [dentistry/README.md](dentistry/README.md).

- **Добавлена оболочка сайта.** Над услугами находится белая закреплённая шапка с логотипом «Люма» и кнопкой записи; ниже формы — полноценный тёмно-синий подвал с направлениями, приглашением на консультацию и крупным белым логотипом. Поэтому общая высота страницы и положение исходных блоков отличаются от драфта. В текущем варианте нет боковой панели и выдвижного меню, упомянутых в старых отчётах.
- **Логотип — отдельное дополнение.** PNG-логотип «Люма» создан в ходе предыдущей работы и подключён вместо нейтрального обозначения клиники. Он не является экспортом исходного логотипа из Figma. В подвале используется его белая версия, полученная CSS-фильтром.
- **Изменены шрифты и иерархия.** Вместо исходного Montserrat основным шрифтом стал Manrope; для заголовка услуг, части заголовков и модальных окон используется Unbounded. Это меняет характер букв, ширину строк и переносы. В актуальном CSS заголовок «Услуги» имеет размер до 36 px на десктопе и 15–20 px на телефоне; упоминание 72 px в DESIGN-REPORT.md относится к предыдущему состоянию.
- **Изменено окружение исходных блоков.** Услуги размещены на ровном светлом фоне, запись — на отдельном мятном поле, подвал — на сплошном тёмно-синем. Сохранена фигурная синяя подложка формы с исходными изображениями. В финальном слое убраны декоративные градиенты окружающих панелей, их тени и стеклянная подложка шапки; градиенты внутри оригинальных изображений остаются.
- **Мобильные карточки укрупнены.** Вместо плотной подачи небольших карточек показаны одна крупная услуга и край следующей. По сохранённому отчёту, на 390 px ширина карточки увеличена примерно со 170 до 291 px. Подписи стали крупнее, а кнопки консультации и подробностей на телефонах имеют одинаковую высоту 44 px. Это улучшает чтение и нажатие, но меняет плотность ряда и увеличивает высоту блока. От 768 px используется раскладка с несколькими карточками.
- **Карусель получила дополнительные видимые состояния.** Стрелки листания стоят по краям фотографий; у начала и конца ряда недоступная стрелка скрыта. Карточки реагируют на наведение, а после перетаскивания ряд выравнивается по позиции услуги.
- **Добавлены окна и состояния формы.** Подробности услуги, запись, валидация, ожидание отправки и результат показаны в отдельных диалогах/уведомлениях. Они дополняют статические экраны драфта. Сообщения явно демонстрационные: подключённого сервиса отправки заявок нет.
- **Добавлена анимация.** Заголовки, фотографии и подвал появляются последовательно, логотип раскрывается, портрет слегка смещается при прокрутке. При prefers-reduced-motion движение отключается. Поэтому промежуточный кадр может отличаться от неподвижного макета.

При этом сохранены девять услуг в исходном порядке, исходные фотографии и маски карточек, изображения формы и её основные поля. Браузерная адаптация между опорными размерами выполнена через CSS и JavaScript, поэтому не повторяет фиксированные координаты драфта на каждой ширине.

Эти визуальные изменения уже присутствовали в локальной «Люме» **до объединения проектов**. При настройке общего сервера её оформление не перерабатывалось.

Подробнее: [актуальные мобильные карточки](dentistry/MOBILE-CARDS.md), [история оформления](dentistry/DESIGN-REPORT.md). Конечный слой стилей — dentistry/studio.css, подключённый после остальных CSS.

### «Додзё Медиа»: сохранена композиция, добавлена браузерная адаптация

Основа сравнения — фреймы 559:95 (1440 × 1672), 559:143 (390 × 2232,25) и 559:187 (мобильное раскрытое меню), перечисленные в [dojo-media/README.md](dojo-media/README.md).

- **Основное оформление сохранено.** Кремовый фон, фиолетовый акцент, Oranienbaum и Manrope, исходные изображения, тонкие разделители, три проектные карточки и структура секций соответствуют принятому локальному макету. Общая тёмная галерея не переносит свои стили внутрь этого сайта.
- **Промежуточные ширины адаптированы самостоятельно.** По локальному отчёту, отдельного планшетного фрейма не было. До 900 px применяется мобильная композиция с шириной содержимого до 600 px; на 901–1279 px уменьшается типографика и сохраняются три карточки в ряд. На 320 px заголовок контактов переносится на две строки. Это решения для размеров между исходными экранами, а не точное воспроизведение отдельного Figma-фрейма.
- **Иллюстрация мастерской анимирована через Remotion.** Она сдвигается на 8 px и приходит в исходное положение за 0,9 секунды. В финальном кадре композиция возвращается к статическому изображению; при reduced motion сразу показывается неподвижный оригинал. Добавлены также короткие появления текста и карточек.
- **Согласован фон иллюстрации.** К изображению мастерской и плееру применяется mix-blend-mode: darken, чтобы светлая подложка изображения сочеталась с фоном страницы. Исходный файл картинки не изменён, но её отображение учитывает цвет подложки.
- **Убрана белая подложка иконки мобильного меню.** В текущем варианте иконка находится на фоне страницы; это исправление зафиксировано в локальном README.
- **Есть дополнительные состояния взаимодействия.** Loading/disabled карточек, демонстрационное уведомление об ошибке и видимый клавиатурный фокус появляются при действиях пользователя. Они не видны на обычном неподвижном экране макета.

Во время объединения изменены только технические пути изображений и базовый адрес Vite; типографика, расположение секций и поведение Remotion сохранены.

### Стартовая галерея: самостоятельная страница

У общей стартовой страницы нет исходного Figma-драфта. Это новая композиция: почти чёрный фон, белая крупная типографика Manrope, золотистые кнопки и два локальных скриншота существующих сайтов. На широком экране превью, заголовки и кнопки обеих работ стоят на одном уровне; на телефоне карточки идут последовательно. Первоначальное вертикальное смещение второй карточки убрано по замечанию пользователя.

Превью — уменьшенные снимки страниц, а не их интерактивные копии. При открытии ссылки загружается полноценный сайт с собственной цветовой схемой и адаптивностью. На галерее ровно две основные ссылки; дополнительных секций и кнопок внутри дочерних сайтов не добавлено.

### Границы точности сравнения

Это описание реализованных решений и известных отклонений, а не заявление о полном пиксельном совпадении. Сглаживание шрифтов, дробные размеры и переносы в браузере могут отличаться от Figma. Старые координаты блоков и оценки из отчётов не следует считать актуальным измерением после всех последующих правок. Для строгой приёмки потребуется новое сравнение текущих страниц с выбранной версией Figma на одинаковых размерах экрана.

## Установка и запуск

Нужны Node.js 22.12+ и npm. В PowerShell:

```powershell
cd C:\projects\dojo-test
npm ci
npm run dev
```

Корневой npm ci автоматически выполняет npm ci внутри dojo-media через postinstall. Сохранены отдельные lock-файлы корня и React-проекта; зависимости не требуют двух ручных установок. У Люмы нет внешних npm-зависимостей.

- Старт: http://localhost:5173/
- Люма: http://localhost:5173/dentistry/
- Додзё Медиа: http://localhost:5173/dojo-media/

Один HTTP-сервер обслуживает все три адреса. Vite работает как middleware этого сервера, включая HMR на том же порту. Второй сервер или iframe не используется. Порт задаётся флагом или переменной PORT, хост — --host или HOST:

```powershell
npm run dev -- --port 5180
# Альтернатива: $env:PORT = "5180"; npm run dev
```

Ссылки страниц относительные, без localhost и номера порта. Для остановки нажмите Ctrl+C.

## Сборка, тесты и предпросмотр

```powershell
npm run build
npm test
npm run preview
```

Build запускает TypeScript, собирает React с base: './' и копирует только статические файлы галереи и Люмы. Результат: dist/index.html, dist/dentistry/index.html, dist/dojo-media/index.html и их ресурсы. Исходники сервера, node_modules и отчёты в dist не попадают. npm test требует готовый dist и проверяет два варианта базового пути, ресурсы, редиректы, отсутствие SPA fallback и существующие тесты mock формы.

Preview использует тот же сервер в статическом режиме, без Vite. По умолчанию порт 5173, поэтому остановите dev или выберите другой порт:

```powershell
npm run preview -- --port 5174
npm run preview -- --port 5174 --base /dojo-test/
```

Для второго примера откройте http://localhost:5174/dojo-test/, затем /dojo-test/dentistry/ и /dojo-test/dojo-media/. Флаг --base (или SITE_BASE) только монтирует неизменный dist под префиксом: повторная сборка для имени репозитория не нужна. Этот флаг поддерживается также dev. Префикс должен начинаться и заканчиваться косой чертой. Неизвестный путь возвращает настоящий 404; сервер не подменяет его index.html. Страницы открываются и обновляются по адресам каталогов; внутренних SPA-маршрутов нет, только якоря.

## Что изменено

- Корень: независимая HTML/CSS-галерея, ровно две ссылки, локальные WebP-превью, шрифт Manrope с OFL, общий сервер, сборка и тесты. Стили не загружаются дочерними сайтами.
- dentistry: исходная вёрстка, CSS и обработчики сохранены. В index.html добавлен пустой favicon для устранения автоматического запроса несуществующего favicon.ico. Старый server.mjs и start.cmd сохранены для отдельного запуска; общий запуск ими не пользуется.
- dojo-media: пути к изображениям/иконкам, включая Remotion, используют import.meta.env.BASE_URL. Добавлены vite-env.d.ts, относительный base в vite.config.mjs и favicon. Исходный lazy import и поведение плеера сохранены. Собственная сборка и запуск проекта также доступны из его каталога.
- .gitignore исключает node_modules, dist, локальные previews/verification/.taste-skill, логи, временные отчёты и .env. Существующие полезные файлы и дочерний package-lock.json сохранены.

## Публикация на GitHub Pages позже

Репозиторий проекта: https://github.com/maxr0zen/dojo-test. Загрузка исходников сама по себе не публикует сайт. Для будущего размещения:

1. Сохраните в репозитории оба package-lock.json. Не добавляйте игнорируемые каталоги.
2. В Settings → Pages → Build and deployment выберите GitHub Actions.
3. Push в ветку main автоматически запускает сборку и тесты без публикации. Для публикации запустите workflow «Publish static gallery to GitHub Pages» вручную из Actions. Если основная ветка называется иначе, измените branches в .github/workflows/pages.yml.
4. При ручном запуске workflow установит зависимости, выполнит build и test, загрузит dist и опубликует Pages. Нужны разрешения Pages write и id-token write, уже указанные в workflow.

Для project Pages адрес будет https://OWNER.github.io/REPOSITORY/, для пользовательского репозитория OWNER.github.io или собственного домена — корень домена. Одинаковый dist подходит для обоих случаев. Сохраняйте имена каталогов dentistry/ и dojo-media/ и структуру ресурсов. .nojekyll создаётся сборкой.

## Ограничения

Формы Люмы остаются демонстрационными: первый корректный submit показывает ошибку для проверки повтора, следующий — успех; данные в клинику не отправляются. Карточки Додзё используют существующий mock, контактные ссылки — mailto. Реальная отправка заявок не добавлялась. Предупреждение Vite об игнорировании 'use client' из @remotion/player не мешает клиентской сборке. Проверка на настоящем GitHub Pages и в Firefox/Safari не проводилась.

Результаты выполненной браузерной проверки и осознанные исключения taste-skill описаны в QA.md.
